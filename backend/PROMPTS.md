1. Задача прочитать тестовое задание из файла TZ.txt, необхоимо проанализировать ТЗ и составить план архитектуры(папки, файлы)
2. Проанализируй файл с ТЗ TZ.txt, необходимо в папке models request.py, user.py написать модели для Request, User с помощью SQLAlchemy, использкуя mapped_column
3. Задача реализовать согласно ТЗ service, endpoint api для requests разделяя права доступа.
4. Реализовать фикстуры, тесты, для проверки системы работы с requests. Какие тесты с проверкой предложишь?
5. Задача реализовать согласно ТЗ service, endpoint api для master разделяя права доступа.
6. Реализовать фикстуры, тесты, для проверки системы работы с master по аналогии с requests используя фикстуры.
7. Нужно реализовать фронт на react, для начала сделать главную страницу и страницу для входа, все эндпоинты по авторизации лежат в auth.py. Такого вида: главная страница, справа вверху кнопка Вход, открывается окно с полями Имя пользователя, пароль, конпка регистрация, кнопка вход
8. Теперь нужно реализовать фронт страницу для личного кабинета Диспетчера, согласно эндпоинтам из файла requests.py
9. Необходимо реализовать фронт страницу для личного кабинета Мастера, согласно эндпоинтам из файла master.py
10. Нужен файл seed.py, который будет создавать в БД сиды, а именно: минимум: 1 диспетчер, 2 мастера, несколько заявок для проверки, используя файлы database.py и models/request.py, user.py
11. Нужен скрипт, который будет при выполнении команды docker compose up --build создавать/проверять сидов из файла seed.py. Если уже есть - пропускаем.
